# ORION Scholar

## Pages

- `home.html`
- `index.html`
- `projects.html`
- `announcements.html`
- `portfolio.html` (researcher profiles, opened from the directory)

## Running Locally

```sh
python3 -m http.server 8000
```

<http://localhost:8000/home.html>. The other pages are available at `/index.html` and `/projects.html`.

## Code style and data

HTML, CSS, and JavaScript use consistent Prettier formatting. `data.json` is formatted JSON; JSON does not allow comments, so field names and the page code describe how the data is used.
